# Appendix 4: Higher Order Polynomial High Pass Filters

## A4.1 Derivation of Quartic Indicators

### A4.1.1 Quartic Velocity Indicator

A quartic function is a fourth order polynomial of the form:

$$x(t) = at^4 + bt^3 + ct^2 + dt + e \tag{A4.1}$$

where $t$ is a continuous variable, $a, b, c, d$ and $e$ are constant coefficients.

For discrete time signals, Eq (A4.1) can be written as

$$x(n) = an^4 + bn^3 + cn^2 + dn + e \tag{A4.2}$$

where $n$ is an integer.

We are interested to find the derivative of the quartic function at $n = 0$, which is the most recent data point.

From Eq (A4.2), we write

$$x_0 = x(0) = e \tag{A4.3a}$$

$$x_{-1} = x(-1) = a - b + c - d + e \tag{A4.3b}$$

$$x_{-2} = x(-2) = 16a - 8b + 4c - 2d + e \tag{A4.3c}$$

$$x_{-3} = x(-3) = 81a - 27b + 9c - 3d + e \tag{A4.3d}$$

$$x_{-4} = x(-4) = 256a - 64b + 16c - 4d + e \tag{A4.3e}$$

Solving Eq (A4.3a-e) for $a, b, c, d$ and $e$ by using determinants, we get

$$a = (1/24)x_0 - (1/6)x_{-1} + (1/4)x_{-2} - (1/6)x_{-3} + (1/24)x_{-4} \tag{A4.4a}$$

$$b = (5/12)x_0 - (3/2)x_{-1} + 2x_{-2} - (7/6)x_{-3} + (1/4)x_{-4} \tag{A4.4b}$$

$$c = (35/24)x_0 - (13/3)x_{-1} + (19/4)x_{-2} - (7/3)x_{-3} + (11/24)x_{-4} \tag{A4.4c}$$

$$d = (25/12)x_0 - 4x_{-1} + 3x_{-2} - (4/3)x_{-3} + (1/4)x_{-4} \tag{A4.4d}$$

$$e = x_0 \tag{A4.4e}$$

Taking the derivative of Eq (A4.1) and then substitute $t$ with $n$, we arrive at

$$\frac{dx}{dn} = 4an^3 + 3bn^2 + 2cn + d \tag{A4.5}$$

At $n = 0$,

$$\frac{dx}{dn}\bigg|_{n=0} = d = \frac{25}{12}x_0 - 4x_{-1} + 3x_{-2} - \frac{4}{3}x_{-3} + \frac{1}{4}x_{-4} \tag{A4.6}$$

We will define the unit sample response $h$ of the quartic velocity indicator as

$$h = (h(0), h(1), h(2), h(3), h(4)) = (25/12, -4, 3, -4/3, 1/4) \tag{A4.7}$$

Thus the output response is given by the convolution sum

$$y(n) = \frac{25}{12}x(n) - 4x(n-1) + 3x(n-2) - \frac{4}{3}x(n-3) + \frac{1}{4}x(n-4) \tag{A4.8}$$

The frequency response or the Discrete Time Fourier Transform (DTFT) of $h$ is given by

$$H(\omega) = 25/12 - 4\exp(-i\omega) + 3\exp(-2i\omega) - (4/3)\exp(-3i\omega) + (1/4)\exp(-4i\omega) \tag{A4.9}$$

### A4.1.2 Quartic Acceleration Indicator

Taking the second derivative of Eq (A4.1) and then substitute $t$ with $n$, we arrive at

$$\frac{d^2x}{dn^2} = 12an^2 + 6bn + 2c \tag{A4.10}$$

At $n = 0$,

$$\frac{d^2x}{dn^2}\bigg|_{n=0} = 2c = \frac{35}{12}x_0 - \frac{26}{3}x_{-1} + \frac{19}{2}x_{-2} - \frac{14}{3}x_{-3} + \frac{11}{12}x_{-4} \tag{A4.11}$$

We will define the unit sample response $h$ of the quartic acceleration indicator as

$$h = (h(0), h(1), h(2), h(3), h(4)) = (35/12, -26/3, 19/2, -14/3, 11/12) \tag{A4.12}$$

Thus the output response is given by the convolution sum

$$y(n) = \frac{35}{12}x(n) - \frac{26}{3}x(n-1) + \frac{19}{2}x(n-2) - \frac{14}{3}x(n-3) + \frac{11}{12}x(n-4) \tag{A4.13}$$

The frequency response or the Discrete Time Fourier Transform (DTFT) of $h$ is given by

$$H(\omega) = 35/12 - (26/3)\exp(-i\omega) + (19/2)\exp(-2i\omega) - (14/3)\exp(-3i\omega) + (11/12)\exp(-4i\omega) \tag{A4.14}$$

## A4.2 Derivation of Quintic Indicators

### A4.2.1 Quintic Velocity Indicator

A quintic function is a fifth order polynomial of the form:

$$x(t) = at^5 + bt^4 + ct^3 + dt^2 + et + f \tag{A4.15}$$

where $t$ is a continuous variable, $a, b, c, d, e$ and $f$ are constant coefficients.

For discrete time signals, Eq (A4.15) can be written as

$$x(n) = an^5 + bn^4 + cn^3 + dn^2 + en + f \tag{A4.16}$$

where $n$ is an integer.

We are interested to find the derivative of the quintic function at $n = 0$, which is the most recent data point.

From Eq (A4.16), we write

$$x_0 = x(0) = f \tag{A4.17a}$$

$$x_{-1} = x(-1) = -a + b - c + d - e + f \tag{A4.17b}$$

$$x_{-2} = x(-2) = -32a + 16b - 8c + 4d - 2e + f \tag{A4.17c}$$

$$x_{-3} = x(-3) = -243a + 81b - 27c + 9d - 3e + f \tag{A4.17d}$$

$$x_{-4} = x(-4) = -1024a + 256b - 64c + 16d - 4e + f \tag{A4.17e}$$

$$x_{-5} = x(-5) = -3125a + 625b - 125c + 25d - 5e + f \tag{A4.17f}$$

Solving Eq (A4.17a-f) for $a, b, c, d, e$ and $f$ by using determinants, we get

$$a = (1/120)x_0 - (1/24)x_{-1} + (1/12)x_{-2} - (1/12)x_{-3} + (1/24)x_{-4} - (1/120)x_{-5} \tag{A4.18a}$$

$$b = (1/8)x_0 - (7/12)x_{-1} + (13/12)x_{-2} - x_{-3} + (11/24)x_{-4} - (1/12)x_{-5} \tag{A4.18b}$$

$$c = (17/24)x_0 - (71/24)x_{-1} + (59/12)x_{-2} - (49/12)x_{-3} + (41/24)x_{-4} - (1/12)x_{-5} \tag{A4.18c}$$

$$d = (15/8)x_0 - (77/12)x_{-1} + (107/12)x_{-2} - (13/2)x_{-3} + (61/24)x_{-4} - (5/12)x_{-5} \tag{A4.18d}$$

$$e = (137/60)x_0 - 5x_{-1} + 5x_{-2} - (10/3)x_{-3} + (5/4)x_{-4} - (1/5)x_{-5} \tag{A4.18e}$$

$$f = x_0 \tag{A4.18f}$$

Taking the derivative of Eq (A4.15) and then substitute $t$ with $n$, we arrive at

$$\frac{dx}{dn} = 5an^4 + 4bn^3 + 3cn^2 + 2dn + e \tag{A4.19}$$

At $n = 0$,

$$\frac{dx}{dn}\bigg|_{n=0} = e = \frac{137}{60}x_0 - 5x_{-1} + 5x_{-2} - \frac{10}{3}x_{-3} + \frac{5}{4}x_{-4} - \frac{1}{5}x_{-5} \tag{A4.20}$$

We will define the unit sample response $h$ of the quintic velocity indicator as

$$h = (h(0), h(1), h(2), h(3), h(4), h(5)) = (137/60, -5, 5, -10/3, 5/4, -1/5) \tag{A4.21}$$

Thus the output response is given by the convolution sum

$$y(n) = \frac{137}{60}x(n) - 5x(n-1) + 5x(n-2) - \frac{10}{3}x(n-3) + \frac{5}{4}x(n-4) - \frac{1}{5}x(n-5) \tag{A4.22}$$

The frequency response or the Discrete Time Fourier Transform (DTFT) of $h$ is given by

$$H(\omega) = 137/60 - 5\exp(-i\omega) + 5\exp(-2i\omega) - (10/3)\exp(-3i\omega) + (5/4)\exp(-4i\omega) - (1/5)\exp(-5i\omega) \tag{A4.23}$$

### A4.2.2 Quintic Acceleration Indicator

Taking the second derivative of Eq (A4.15) and then substitute $t$ with $n$, we arrive at

$$\frac{d^2x}{dn^2} = 20an^3 + 12bn^2 + 6cn + 2d \tag{A4.24}$$

At $n = 0$,

$$\frac{d^2x}{dn^2}\bigg|_{n=0} = 2d = \frac{15}{4}x_0 - \frac{77}{6}x_{-1} + \frac{107}{6}x_{-2} - 13x_{-3} + \frac{61}{12}x_{-4} - \frac{5}{6}x_{-5} \tag{A4.25}$$

We will define the unit sample response $h$ of the quintic acceleration indicator as

$$h = (h(0), h(1), h(2), h(3), h(4), h(5)) = (15/4, -77/6, 107/6, -13, 61/12, -5/6) \tag{A4.26}$$

Thus the output response is given by the convolution sum

$$y(n) = \frac{15}{4}x(n) - \frac{77}{6}x(n-1) + \frac{107}{6}x(n-2) - 13x(n-3) + \frac{61}{12}x(n-4) - \frac{5}{6}x(n-5) \tag{A4.27}$$

The frequency response or the Discrete Time Fourier Transform (DTFT) of $h$ is given by

$$H(\omega) = 15/4 - (77/6)\exp(-i\omega) + (107/6)\exp(-2i\omega) - 13\exp(-3i\omega) + (61/12)\exp(-4i\omega) - (5/6)\exp(-5i\omega) \tag{A4.28}$$

## A4.3 Derivation of Sextic Indicators

### A4.3.1 Sextic Velocity Indicator

A sextic function is a sixth order polynomial of the form:

$$x(t) = at^6 + bt^5 + ct^4 + dt^3 + et^2 + ft + g \tag{A4.29}$$

where $t$ is a continuous variable, $a, b, c, d, e, f$ and $g$ are constant coefficients.

For discrete time signals, Eq (A4.29) can be written as

$$x(n) = an^6 + bn^5 + cn^4 + dn^3 + en^2 + fn + g \tag{A4.30}$$

where $n$ is an integer.

We are interested to find the derivative of the sextic function at $n = 0$, which is the most recent data point.

From Eq (A4.30), we write

$$x_0 = x(0) = g \tag{A4.31a}$$

$$x_{-1} = x(-1) = a - b + c - d + e - f + g \tag{A4.31b}$$

$$x_{-2} = x(-2) = 64a - 32b + 16c - 8d + 4e - 2f + g \tag{A4.31c}$$

$$x_{-3} = x(-3) = 729a - 243b + 81c - 27d + 9e - 3f + g \tag{A4.31d}$$

$$x_{-4} = x(-4) = 4096a - 1024b + 256c - 64d + 16e - 4f + g \tag{A4.31e}$$

$$x_{-5} = x(-5) = 15625a - 3125b + 625c - 125d + 25e - 5f + g \tag{A4.31f}$$

$$x_{-6} = x(-6) = 46656a - 7776b + 1296c - 216d + 36e - 6f + g \tag{A4.31g}$$

Solving Eq (A4.31a-g) for $a, b, c, d, e, f$ and $g$ by using determinants, we get

$$a = (34560 x_0 - 207360 x_{-1} + 518400 x_{-2} - 691200 x_{-3} + 518400 x_{-4} - 207360 x_{-5} + 34560 x_{-6})/24883200 \tag{A4.32a}$$

$$b = (725760 x_0 - 4147200 x_{-1} + 9849600 x_{-2} - 12441600 x_{-3} + 8812800 x_{-4} - 3317760 x_{-5} + 518400 x_{-6})/24883200 \tag{A4.32b}$$

$$c = (6048000 x_0 - 32140800 x_{-1} + 71020800 x_{-2} - 83635200 x_{-3} + 55468800 x_{-4} - 19699200 x_{-5} + 2937600 x_{-6})/24883200 \tag{A4.32c}$$

$$d = (25401600 x_0 - 120268800 x_{-1} + 238982400 x_{-2} - 257126400 x_{-3} + 159148800 x_{-4} - 53913600 x_{-5} + 7776000 x_{-6})/24883200 \tag{A4.32d}$$

$$e = (56125440 x_0 - 216483840 x_{-1} + 363916800 x_{-2} - 351129600 x_{-3} + 205286400 x_{-4} - 67184640 x_{-5} + 9469440 x_{-6})/24883200 \tag{A4.32e}$$

$$f = \frac{49}{20}x_0 - 6x_{-1} + \frac{15}{2}x_{-2} - \frac{20}{3}x_{-3} + \frac{15}{4}x_{-4} - \frac{6}{5}x_{-5} + \frac{1}{6}x_{-6} \tag{A4.32f}$$

$$g = x_0 \tag{A4.32g}$$

Taking the derivative of Eq (A4.29) and then substitute $t$ with $n$, we arrive at

$$\frac{dx}{dn} = 6an^5 + 5bn^4 + 4cn^3 + 3dn^2 + 2en + f \tag{A4.33}$$

At $n = 0$,

$$\frac{dx}{dn}\bigg|_{n=0} = f = \frac{49}{20}x_0 - 6x_{-1} + \frac{15}{2}x_{-2} - \frac{20}{3}x_{-3} + \frac{15}{4}x_{-4} - \frac{6}{5}x_{-5} + \frac{1}{6}x_{-6} \tag{A4.34}$$

We will define the unit sample response $h$ of the sextic velocity indicator as

$$h = (h(0), h(1), h(2), h(3), h(4), h(5), h(6)) = (49/20, -6, 15/2, -20/3, 15/4, -6/5, 1/6) \tag{A4.35}$$

Thus the output response is given by the convolution sum

$$y(n) = \frac{49}{20}x(n) - 6x(n-1) + \frac{15}{2}x(n-2) - \frac{20}{3}x(n-3) + \frac{15}{4}x(n-4) - \frac{6}{5}x(n-5) + \frac{1}{6}x(n-6) \tag{A4.36}$$

The frequency response or the Discrete Time Fourier Transform (DTFT) of $h$ is given by

$$H(\omega) = 49/20 - 6\exp(-i\omega) + (15/2)\exp(-2i\omega) - (20/3)\exp(-3i\omega) + (15/4)\exp(-4i\omega) - (6/5)\exp(-5i\omega) + (1/6)\exp(-6i\omega) \tag{A4.37}$$

### A4.3.2 Sextic Acceleration Indicator

Taking the second derivative of Eq (A4.29) and then substitute $t$ with $n$, we arrive at

$$\frac{d^2x}{dn^2} = 30an^4 + 20bn^3 + 12cn^2 + 6dn + 2e \tag{A4.38}$$

At $n = 0$,

$$\frac{d^2x}{dn^2}\bigg|_{n=0} = 2e = 4.5112x_0 - 17.4x_{-1} + 29.25x_{-2} - 28.2222x_{-3} + 16.5x_{-4} - 5.4x_{-5} + 0.7612x_{-6} \tag{A4.39}$$

We will define the unit sample response $h$ of the sextic acceleration indicator as

$$h = (h(0), h(1), h(2), h(3), h(4), h(5), h(6)) = (4.5112, -17.4, 29.25, -28.2222, 16.5, -5.4, 0.7612) \tag{A4.40}$$

Thus the output response is given by the convolution sum

$$y(n) = 4.5112x(n) - 17.4x(n-1) + 29.25x(n-2) - 28.2222x(n-3) + 16.5x(n-4) - 5.4x(n-5) + 0.7612x(n-6) \tag{A4.41}$$

The frequency response or the Discrete Time Fourier Transform (DTFT) of $h$ is given by

$$H(\omega) = 4.5112 - 17.4\exp(-i\omega) + 29.25\exp(-2i\omega) - 28.2222\exp(-3i\omega) + 16.5\exp(-4i\omega) - 5.4\exp(-5i\omega) + 0.7612\exp(-6i\omega) \tag{A4.42}$$
