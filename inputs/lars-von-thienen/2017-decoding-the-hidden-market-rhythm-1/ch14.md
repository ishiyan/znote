### Public Application Programming Interface ("API")

Since 2017, we have also offered public API integration for the presented cycle tools. An Application Programming Interface (API) is a set of programming instructions and standards for accessing web-based software applications. We released our cycles API to the public so other software developers can integrate cycle tools into different solutions and charting platforms. An API is a software-to-software interface, not a user interface. The API resembles "software as a service" (SaaS) for our cycle tools, as developers do not have to start from scratch every time they write an indicator or trading system based on cycle analysis. Instead of building a monolithic application that does everything—like charting, trading, and cycle analysis—an application can outsource specific cycle analysis responsibilities to our remote cycle engine. Developers and users are thus free to choose their preferred application and integrate it with our cycle tools via the public API.
