### 8.6. Dynamic / Manual Cycle Explorer

The Dynamic Cycle Explorer script combines different cycle analysis and calculation routines into one script. Itis primarily used to check static cycles and the presence of these cycles in the price. Accordingly, the cycle’s detection algorithms are used and combined with a visual plotting mechanism.

The visual plot makes it possible to verify whether specific cycles have been active over time and to “see” the phase and amplitude shifts of the cycle under review. Dynamic in this regard means that it re-checks the most dominant cycle at each new bar and adjusts the visual plot based on this information. Ic has a fixed look-back period that is anchored to one bar.

It combines techniques introduced by Hurst and Millard with my own forecasting techniques, which are introduced in Chapter 5.2: “Introduction of the Dynamic Cycle Explorer” on page 7iff.

Script input:

- Range for cycle lengths that should be taken into account for auto-detection (dynamic model only)
- Specific cycle length that should be used (manual model only)
- Set anchor to bar on chart where the data analysis should begin (up to current bar)
- Different plotting configuration settings.

Script output:

- Ideal cycle plot of the cycle length
- Real extracted cyclic price behavior of the cycle length (average-minus-average method)
- Overlay of both plots to identify phase, amplitude, and length fittings, correlations and shifts
- Projection plot of ideal cycle into the future.

The difference between the Dynamic and Manual Cycle Explorer is that the dynamic model automatically detects and adjusts itself to the dominant cycle whereby the manual model requires fixed input for the cycle length to be reviewed.
