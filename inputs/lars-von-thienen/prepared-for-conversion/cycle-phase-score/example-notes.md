# Example provenance

example-prices.csv contains the exact supplied 252 INPUT_CLOSE values on an
explicitly synthetic 2020 calendar: evenly selected weekdays, covering January
through December. These dates are artificial, not the original price dates
or an exchange holiday calendar. The numerical price inputs are unchanged.

The saved report/series or annual model/wave use the CLI default parameters.
They are runnable demonstrations of local file workflows, not reproductions
of a book chart. Annual model fitting has already finished before its wave
is exported.
