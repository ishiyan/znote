## 3. Key Themes from Each Book

### Part 1: Dynamic Cycles
- **Dynamic vs. static cycles**: First book to present a dynamic dominant cycle approach that updates in real-time at the right edge of the chart, contrasting with traditional static cycle extrapolation
- **Digital Signal Processing (DSP)**: Uses FFT, DFT-Goertzel algorithms, and spectral analysis for cycle detection
- **Dominant Cycle framework**: Identifies the current "dominant cycle" (wavelength, phase, amplitude) that morphs over time
- **Multi-market validation**: S&P 500, Dow, Gold, Silver, Forex (EUR/USD, GBP/USD), VIX sentiment data, Financial Stress Index
- **Intellectual lineage**: Builds on J.M. Hurst (1970), John Ehlers (2013), B.J. Millard (1999)
- **Practical emphasis**: "Simplicity for analyzing markets rather than mathematical purity"
- **Source code democratization**: 3rd edition opened source code repository for NinjaTrader, MetaTrader, C++, Excel, cloud APIs

### Part 2: Metonic Cycles
- **External energy cycles**: Correlates markets with solar/lunar/geomagnetic/gravitational cycles
- **Gann's master cycles reverse-engineered**: Uses DSP to decode Gann's hidden cycles
- **Sentiment predictor**: A cyclic sentiment predictor for the DJIA using daily data from 1935–2013
- **Mechanical trading system**: 100% mechanical, cycle-based system reporting 20% CAGR over 30 years on the Dow
- **Non-linear indicators**: Introduces "cyclic time" vs. linear-time indicators
- **Statistical verification**: "In-depth statistical verification analysis demonstrating results are not based on luck"
- **Ancient cycles thesis**: Ancient (Metonic) cycles used as predictors for daily market sentiment years ahead
- **Astronomical/astrological framing**: Markets driven by emotions; emotions influenced by Sun/Moon/Earth interactions
- **TradeStation/EasyLanguage code**: Full rebuildable indicators and trading systems included
