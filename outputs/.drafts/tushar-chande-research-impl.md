## 5. Complete Indicator Documentation

### 5.1 CMO — Chande Momentum Oscillator

| Property | Value |
|----------|-------|
| **Category** | Oscillator |
| **Formula** | `CMO = 100 × (Sum_Up - Sum_Down) / (Sum_Up + Sum_Down)` |
| **Where** | Sum_Up = sum of positive price changes over n periods; Sum_Down = sum of absolute negative price changes over n periods |
| **Range** | -100 to +100 |
| **Default Period** | 9 or 14 |
| **Overbought/Oversold** | +50 / -50 |
| **First Publication** | *The New Technical Trader* (1994), also TASC articles ~1993 |
| **Notes** | Similar to RSI but uses both up and down sums in numerator; symmetric around zero |

### 5.2 VIDYA — Variable Index Dynamic Average

| Property | Value |
|----------|-------|
| **Category** | Adaptive Moving Average |
| **Formula** | `VIDYA(t) = Price × F × VI + VIDYA(t-1) × (1 - F × VI)` |
| **Where** | `VI = |CMO(n)| / 100` (Volatility Index); `F = 2 / (period + 1)` (EMA smoothing constant) |
| **Default Parameters** | CMO period: 9; EMA period: 12 |
| **First Publication** | *The New Technical Trader* (1994); refined in *Beyond Technical Analysis* (1997, p.36 2nd ed) |
| **Notes** | Adapts speed based on CMO volatility; fast in trends, slow in ranges; MetaTrader 5 built-in indicator (iVIDyA) |

### 5.3 Aroon Up/Down & Aroon Oscillator

| Property | Value |
|----------|-------|
| **Category** | Trend Identification |
| **Formula (Up)** | `Aroon Up = 100 × (period - bars_since_highest_high) / period` |
| **Formula (Down)** | `Aroon Down = 100 × (period - bars_since_lowest_low) / period` |
| **Formula (Oscillator)** | `Aroon Oscillator = Aroon Up - Aroon Down` |
| **Range** | 0–100 (Up/Down); -100 to +100 (Oscillator) |
| **Default Period** | 25 (represents ~1 month of trading days) |
| **First Publication** | TASC, September 1995 |
| **Notes** | "Aroon" = Sanskrit for "dawn's early light"; identifies trend beginnings; author CEO of Tuscarora Capital |

### 5.4 RAVI — Range Action Verification Index

| Property | Value |
|----------|-------|
| **Category** | Trend Filter |
| **Formula** | `RAVI = |SMA(short) - SMA(long)| / SMA(long) × 100` |
| **Default Parameters** | Short SMA: 7; Long SMA: 65 (quarterly); Threshold: ±3% (or ±0.3% / ±0.1%) |
| **First Publication** | *Beyond Technical Analysis* (1997) |
| **Notes** | Similar concept to ADX but simpler; above threshold = trending, below = ranging |

### 5.5 StochRSI — Stochastic RSI

| Property | Value |
|----------|-------|
| **Category** | Oscillator |
| **Formula** | `StochRSI = (RSI - Min(RSI, n)) / (Max(RSI, n) - Min(RSI, n))` |
| **Range** | 0 to 1 (or 0–100 when scaled) |
| **Default Parameters** | RSI period: 14; Stochastic period: 14 |
| **Authors** | Tushar S. Chande & Stanley Kroll |
| **First Publication** | *The New Technical Trader* (1994); TASC article 1992 |
| **Notes** | Applies stochastic formula to RSI values; more sensitive than RSI alone; widely adopted |

### 5.6 QStick

| Property | Value |
|----------|-------|
| **Category** | Trend / Candlestick Quantification |
| **Formula** | `QStick = MA(Close - Open, n)` |
| **Default Period** | 8 |
| **First Publication** | *The New Technical Trader* (1994) |
| **Notes** | Positive = dominance of white/bullish candles; negative = dominance of black/bearish candles; can use SMA or EMA |

### 5.7 Dynamic Momentum Index (DMI)

| Property | Value |
|----------|-------|
| **Category** | Oscillator (Adaptive RSI) |
| **Formula** | Variable-period RSI where period = `Int(14 / (StdDev(5) / SMA(StdDev(5), 10)))` clamped to [3, 30] |
| **Default Parameters** | Base RSI period: 14; StdDev period: 5; SMA of StdDev: 10; Min period: 3; Max period: 30 |
| **Authors** | Tushar S. Chande & Stanley Kroll |
| **First Publication** | *The New Technical Trader* (1994) |
| **Notes** | Shorter period in high volatility = more responsive; interpreted like RSI (70/30 levels) |

### 5.8 Chandelier Exit / Comfort Zone Stops

| Property | Value |
|----------|-------|
| **Category** | Trailing Stop / Exit Strategy |
| **Formula** | `Long Stop = Highest High(n) - Multiplier × ATR(n)` / `Short Stop = Lowest Low(n) + Multiplier × ATR(n)` |
| **Default Parameters** | Period: 22; ATR multiplier: 3.0 |
| **Attribution** | **Developed by Charles Le Beau**; popularized by Alexander Elder. Chande discussed ATR-based stops in *Beyond Technical Analysis* but the Chandelier Exit is primarily Le Beau's work. |
| **First Publication** | Le Beau's work; Elder's books featured it prominently |
| **Notes** | NOT primarily Chande's indicator — attribution often confused |

### 5.9 Trend Score (Verification Needed)

| Property | Value |
|----------|-------|
| **Category** | Trend Strength |
| **Formula** | Sum of +1/-1 for each of multiple lookback comparisons (e.g., Close > Close[1], Close > Close[2], etc.) |
| **Attribution** | Mentioned in *Beyond Technical Analysis*; less widely implemented than other Chande indicators |
| **Status** | Minor indicator; not widely adopted in platforms |

## 8. Key Findings & Notes

1. **Most prolific indicator author in MQL5 codebase** — More implementations than Mulloy or Tillson combined
2. **VIDYA is a MetaTrader 5 built-in** — Official MetaQuotes implementation (code/75), highlighting its importance
3. **Aroon is universally adopted** — Built-in on TradingView, in TA-Lib, pandas-ta; widely discussed
4. **Chandelier Exit misattribution** — Often associated with Chande but actually by Charles Le Beau (popularized by Elder)
5. **DMI (Dynamic Momentum Index)** — Additional indicator not always listed; variable-period RSI concept
6. **Mass Index** — Popularized by Chande & Dorsey (Donald Dorsey original; Chande popularized)
7. **Company:** Tuscarora Capital Management (CEO)
8. **Collaborator:** Stanley Kroll (co-author, *The New Technical Trader*; co-developer of StochRSI and DMI)
