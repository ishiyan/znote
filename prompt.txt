**SVG color compatibility** � SVGs from web apps often rely on CSS-inherited colors. When copying SVGs, inject a `<style>` block with `prefers-color-scheme` media queries:
   ```xml
   <style>
     svg { stroke: black; fill: black; }
     @media (prefers-color-scheme: dark) {

     }
   </style>

Based on your requirements for a lightweight, embedded C++ library to perform fuzzy numerical comparisons (e.g., "close enough," "crosses," "mean is larger") with an alpha parameter for confidence, the best available free option is:

eFLL (Embedded Fuzzy Logic Library)
Description: A lightweight, MIT-licensed C++ library specifically designed for embedded systems like Arduino. It is portable, uses minimal resources, and has no external dependencies. 
Relevance to Your Needs:
Alpha Parameter: The core concept of fuzzy logic is the membership function, which outputs a value in [0,1].  This value is your alpha. A membership of 1.0 means "crisp true" (e.g., A == B), while a membership of 0.95 means "95% true" (e.g., A is very close to B).
Numerical Comparisons: You can model your conditions using fuzzy sets:
"A is close to B": Define a FuzzySet with a triangular or trapezoidal shape centered at B.
"A crosses B up": Define rules based on the sign change of (A - B) and its derivative.
"Mean of A is larger than B": Calculate the mean and use a "large" or "very large" fuzzy set for comparison.
Embedded Ready: Written in C++/C with only stdlib.h, it is explicitly designed for microcontrollers with limited memory and processing power. 
To implement your logic, you would define FuzzyInput variables (e.g., difference, slope, mean_value), create FuzzySets for conditions like "close," "positive," "large," and then use the library's inference engine to get a crisp output or the membership (alpha) value for your condition. 

https://github.com/alvesoaj/eFLL

fuzzylite
Description: A highly efficient, multi-platform C++ library for fuzzy logic control, also available for Python and Java. It is dual-licensed (GPL 3.0 or commercial). 
Relevance: The GPL 3.0 version is free for open-source projects. It is explicitly noted as "lightweight and efficient" for embedded systems and robotics. Its core engine can be used to implement your numerical conditions, with the membership grade serving as alpha. 

https://github.com/nicopauss/LFLL

simpful is a lightweight Python library for fuzzy logic.  While it supports rules, its core FuzzySet objects can be used to calculate membership grades (your alpha value) for conditions like "A is close to B" by checking the membership of (A - B) in a "zero" set.

https://github.com/aresio/simpful


Both eFLL and fuzzylite support a programmatic approach and are not limited to textual expressions. 

eFLL: Uses a programmatic API where rules are built using objects like FuzzyRuleAntecedent and FuzzyRuleConsequent. For example, you create a rule by joining fuzzy sets with joinSingle() or joinWithAND(), which is code-based, not text-based. 
fuzzylite: Offers both approaches. You can define rules programmatically in C++/Python/Java using the API, or you can parse textual rules (e.g., "if obstacle is left then mSteer is right") using the Rule::parse() method and the FuzzyLite Language (FLL) format. 
Therefore, while both allow for programmatic construction (which fits your need for embedded systems), fuzzylite also provides the flexibility of textual rule definition.
